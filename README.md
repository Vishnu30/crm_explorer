CRM Use Case Explorer — Flat Static Package (Responsive)
=========================================================

This flat package contains:
- index.html
- app.js
- styles.css
- usecases.json

All files are at the repository root for easy GitHub Pages deployment.

How to test locally:
1. Unzip the package and `cd` into the folder.
2. Run a static server (recommended):
   python3 -m http.server 8000
3. Open http://localhost:8000/ and test the UI on multiple viewports.

To deploy:
- Push files to GitHub and enable Pages (branch: main, folder: /).
